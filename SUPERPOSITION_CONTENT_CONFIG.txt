HOW TO USE
----------
1. Edit only the text to the right of each "=".
2. Keep every key and section name unchanged.
3. Leave an optional value blank if you want it omitted.
4. Do not add quotation marks unless you want quotation marks to appear.
5. Save as plain UTF-8 text and upload this file back to ChatGPT.
6. I will compile it into the site, validate it, and generate the next preview.

This worksheet is developer input only. It is intentionally excluded from the
public Cloudflare asset bundle.
